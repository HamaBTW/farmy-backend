# Farmy Backend

Farmy is a platform for farming and agriculture.

## Project Structure

```
farmy/
├── docs/
├── uploads/
│   ├── images/
│   ├── videos/
│   └── temp/
├── src/
│   ├── config/
│   ├── controllers/
│   ├── routes/
│   ├── services/
│   ├── models/
│   ├── middlewares/
│   ├── validators/
│   ├── utils/
│   ├── socket/
│   ├── types/
│   ├── swagger/
│   ├── app.ts
│   └── server.ts
├── .env
├── tsconfig.json
├── package.json
└── README.md
```

## Setup

1. Install dependencies: `npm install`
2. Run in development: `npm run dev`
3. Build for production: `npm run build`
4. Run in production: `npm start`
